This document defines only the primary user of SAT-Dengue V2. Detailed dashboard functionality and information requirements belong to PROD-04.
Primary User — Approved Decision
The primary user is an official of a departmental Health Secretariat responsible for epidemiological surveillance, within the approved Tolima and Meta scope.
For the academic project, no additional segmentation by office, job title, seniority, technical knowledge, training level, or organizational responsibility is required.
The user is a human decision-support consumer. SAT-Dengue does not autonomously execute public-health actions.
Core User Need
The user needs to access the dashboard and identify whether SAT-Dengue is signaling an increased risk of a dengue peak or excess for municipalities within the corresponding department.
The dashboard must support interpretation of the alert for the approved prediction horizons.
Detailed information shown in the dashboard, navigation, visualizations, traffic-light behavior, explanatory fields, historical context, and interaction flows will be defined in PROD-04.
Scope Boundary
This document does not define:
- organizational roles or departmental offices;
- user training or knowledge requirements;
- file preparation responsibilities;
- downstream stakeholders;
- permissions, authentication, or authorization;
- operational response procedures;
- dashboard screens or detailed information architecture.
Those elements are outside the current academic scope unless later required explicitly by the project.
