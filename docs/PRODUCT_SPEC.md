# Product Spec — SAT-Dengue-V2

## Product Goal

SAT-Dengue-V2 is the next-generation engineering baseline for a dengue analytics and decision-support system. The repository currently prioritizes execution governance and AI-agent reliability so future modeling, data processing, and delivery work can be planned and validated with deterministic gates.

## Users and Stakeholders

- Product/technical owner (Mauricio) who defines goals, acceptance, and release decisions.
- Engineering agents (Copilot/Codex-compatible) executing scoped tasks under DWP.
- Future data-science and platform contributors working from a shared repository contract.

## Core Capabilities (Current Stage)

- AI-first repository harness with DWP v7 skill installation.
- Durable planning workflow contract for long-horizon engineering execution.
- Repository governance record for reproducibility and auditability.

## Planned Capability Areas (Next Stages)

- Data ingestion and normalization for dengue-related datasets.
- Analytical or ML pipelines aligned to CRISP-ML(Q).
- Operational interfaces (API/dashboard/notebooks) once explicitly scoped.

## Success Criteria

- Every non-trivial change is executable through a DWP lifecycle.
- Validation gates are explicit, reproducible, and evidence-backed.
- Repository onboarding for new agents requires no hidden context.

## Non-Goals (Current Stage)

- No model training implementation yet.
- No API/dashboard/notebook delivery yet.
- No PITAGORAS integration.
