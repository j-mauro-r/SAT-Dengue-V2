# Product Spec (Entry Document)

Authoritative source: `docs/product/product-definition.md`

## Intent

SAT-Dengue V2 aims to support earlier public health decisions by anticipating outbreak risk before outbreaks are already established.

## Foundation-Level Scope

- Product direction and scientific objective are defined.
- Dashboard functional baseline is defined at concept level.
- Runtime implementation remains out of scope for this stage.
