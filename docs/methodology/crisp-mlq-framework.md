# CRISP-ML(Q) Application for SAT-Dengue V2

## Methodological Frame

SAT-Dengue V2 follows CRISP-ML(Q) as the governing scientific lifecycle.

## Phase Intent in This Repository

- Business and product understanding: decision-support value and operational interpretation.
- Data understanding: epidemiological, climatic, and temporal signal characterization.
- Data preparation: reproducible transformations and quality controls.
- Modeling: comparable candidate model development under shared protocol.
- Evaluation: strict temporal validation, calibration analysis, and operational threshold analysis.
- Deployment planning: API/dashboard contract maturity before release.
- Monitoring and maintenance: drift/performance tracking and model governance.

## Methodological Non-Negotiables

- Temporal leakage prevention is mandatory.
- Training-only metrics are insufficient for model selection.
- Reproducibility and traceability are required for scientific claims.
