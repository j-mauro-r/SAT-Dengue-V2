# AI Agent Onboarding

## First Session Checklist

1. Read [AGENTS.md](../AGENTS.md) end-to-end.
2. Read [docs/README.md](README.md) and [docs/TESTING_GUIDE.md](TESTING_GUIDE.md).
3. Verify repository status: `git status --short --branch`.
4. Validate harness conformance: `bash .agents/skills/deepworkplan/verify/conformance.sh`.
5. For structured work, use `.agents/commands/dwp-create.md` and execute via the corresponding DWP flow.
