# AI Agent Onboarding

## First Session Checklist

1. Read `AGENTS.md`.
2. Read `docs/README.md` and `docs/governance/ai-developer-first.md`.
3. Read `docs/TESTING_GUIDE.md` and `docs/DEVELOPMENT_COMMANDS.md`.
4. Verify branch state: `git status --short --branch`.
5. Run validation baseline from `docs/TESTING_GUIDE.md`.

## Mandatory Behavioral Rules

- Keep work inside repository scope.
- Use authority hierarchy from `docs/README.md`.
- Do not claim completion without evidence states.
- Escalate when scope/authority/security boundaries are unclear.
- Never introduce PITAGORAS.
